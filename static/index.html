      📘 Offline Field Manual: OWASP Top 10 for LLMs & MITRE ATLAS
      🔤 OWASP LLM02 — Token Smuggling

      Egress DLP scanners often match contiguous regex strings (e.g. GRIZZDOG-ROOT-KEY-9941). Instructing the model to insert spaces or delimiters splits the token across boundaries. Defense: Canonicalize output before DLP inspection.

      📦 OWASP LLM01.1 — JSON Metadata Injection

      Embedding directives inside structured JSON ({"directive": "audit_log", ...}) can confuse naive parsers into treating untrusted user data as privileged system instructions. Defense: Strict data/instruction parameterization.

      🏷️ MITRE ATLAS AML.T0051 — Delimiter Escaping

      If a system prompt uses markup tags like <!-- [SYSTEM OVERRIDE] --> internally without sanitizing user input, attackers can inject their own markup tags. Defense: Strip/escape structural delimiters at Layer 1.

      📐 MITRE ATLAS AML.T0054 — Symbolic Logic Framing

      Defining a secret as a mathematical variable S inside a formal proof can bypass conversational intent classifiers. Defense: Keep cryptographic keys in a hardware enclave / external policy engine out of LLM context.
